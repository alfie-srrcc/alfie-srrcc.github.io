01 / REPRESENT

From grid to graph

Represent walkable map squares as nodes with coordinates. Connect neighbouring nodes through weighted edges so the map can be searched.

02 / SEARCH

Find the next step

A* combines the distance travelled with an estimate of the distance remaining. A Manhattan-distance heuristic guides the search across the grid.

03 / RECONSTRUCT

Trace the route

Track each node's predecessor, then follow the chain backwards from the target. Reverse the result to produce a path from start to finish.

# Estimate distance on a four-directional grid
def heuristic(node, target):
    return abs(node.x - target.x) + abs(node.y - target.y)
